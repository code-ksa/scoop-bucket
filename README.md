# AbdoCode Scoop bucket

```powershell
scoop bucket add abdocode https://github.com/code-ksa/scoop-bucket
scoop install abdocode
abdocode
```

`abdocode` opens the terminal interface of AbdoCode, a coding agent that runs on your own machine. Also on npm (`npm install -g abdocode`) and as a desktop app on the [releases page](https://github.com/code-ksa/abdocode/releases).
